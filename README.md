# FinFlow 💰

**Gestão Financeira Pessoal Completa**  
Aplicativo full stack com dashboard web poderoso + app mobile rápido e intuitivo.

## Stack

| Camada       | Tecnologia              |
|--------------|-------------------------|
| Backend      | Ruby on Rails (API)     |
| Web          | Angular + Tailwind CSS  |
| Mobile       | React Native + NativeWind |
| Auth         | JWT + Biometria         |
| Temas        | Light / Dark / **Mercenary** (pago) |

## Funcionalidades Principais

- Lançamentos rápidos (despesa/receita)
- Categorização inteligente
- Gráficos e relatórios
- Metas financeiras
- Notificações push
- Login com biometria (FaceID / Digital)
- **Modo pago "Mercenary"**: tema exclusivo inspirado em Deadpool & Wolverine (cores vermelho/preto/amarelo + texturas)
